A little over a week ago on September 24th and 25th was DevConf.US 2026! This is an open source
software conference that happens every year around this time. I attended the conference last year
in 2025 and one other time in 2022 when I started university to present on a project that I worked
on during a summer program for incoming CS freshman at my university. This year unfortunately I
only attended on the first day being the 24th because of th weather that was expected the next day.
This article is going to quickly cover my time at the conference and how my first time speaking 
at an event like this went.

## Talks I Attended

As I mentioned in the intro, DevConf.US is an open source software conference. There are a ton
of talks about various open source technologies that fit into a few different categories. This
year a majority of the talks covered AI in someway because that's the big topic right now which is
understandable. Below are some highlights from sessions that I went to.

#### OpenClaw Keynote

The first thing that I attended during the day was the keynote which was about OpenClaw. I heard
about this project when it first started but other then that I don't know much about it besides
it was one of the first AI agent platforms (and that it was full of security problems :p)
The talk was given by a couple of OpenClaw maintainers and it was cool to hear about what they use
it for. One cool thing was that they have a research agent who finds articles that they should
take into account. That sounds like a really cool thing that I would love to add to my homelab
but unfortunately hardware for local AI is so expensive and I really don't want to pay that money
for it. Maybe one day...

#### Containers Birds of a Feather

This was my favorite session of this year and also last year. This session is a discussion about
all things containers. It was hosted by a couple of Podman maintainers. They talked about various
topics from the new extension system they want to add into Podman which would allow for more
things to work nicely in there, some performance improvements they want to make, post quantum
cryptography (it's challenges and how its going to disrupt the whole containers ecosystem), and
also how they could make image updates more easy for edge deployments with limited bandwidth.
Listening to these discussions is always awesome because you get to learn some cool things that you
might not know about the internals of container runtimes.

#### Various Intern Presentations

A couple of interns that we had at my company had a presentation on their internship work and
it was cool to hear more about what they did.

#### Netfyr

A friend of mine gave a presentation on a new solution to Linux network management that his team
is working on called netfyr. It is pretty cool and aims to simply the features that were between
network manager and things like nmstate. A feature about it that I found really useful is a
journal that keeps track of all the changes to the network interfaces and allows you to easily
rollback.

#### Distributed Local Model Serving

The final session that I could really interesting was a distributing local model serving project.
It splits local inference across multiple devices which is neat. I did not really understand a lot
here because I am not too familiar with how LLM inference works but it was cool to hear about.
I wish I comprehended more for this but it was right after my talk so I was just out of it haha.

## My Presentation

During this event a gave my first technical talk. It was on a project I have been working on ever
since joining Red Hat earlier this year. That project is Argo CD Agent, a project that switches
Argo CD's multi-cluster experience to be a distributed pull model instead of a push model.
Unfortunately the link to the spliced live stream is not up yet so below is the link to the
timestamped stream:

https://www.youtube.com/live/Sx4r3zmezrE?si=PdtGu42tjE9ZUkUj&t=19494

Talking was pretty nerve wracking at first. I did not want to get anything wrong and look like 
a fool up there. The thing I was the most nervous about was questions but luckily I did not get
asked too many hard ones. I also got some questions after the session so that was cool. A couple
of hardware management people talked to me about how they might use our project with their platform
teams to make it so they could split things based on the CPU architecture of the hardware.
My live demo environment also decided not to work that day so I had to go with my video which I
think the text might be a little too small because it was recorded on an ultra wide.

For self critism, I think I talked a little to fast and could have probably talked slower. I think
I did a good job on talking about the background problem but that might have led the presentation
to be too long but overall pretty ok for my first talk.

## Conclusion

DevConf.US 2026 was a really fun event as it always is. I wish that the weather wasn't going to be
bad so I could have gone the second day but it is what it is. I will be excited for next year.
If you are in the Boston area I highly recommend coming. There's a lot to learn and a good place to
network with other fellow open source enthusiast. Thanks for reading and I'll see you guys in 
the next one.
